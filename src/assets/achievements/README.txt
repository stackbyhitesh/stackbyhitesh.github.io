Put your award / certificate images in this folder, using these exact file names
(any of .jpg .jpeg .png .webp .avif):

  heros.jpg            -> Hero's Award
  prodigy.jpg          -> Prodigy Award
  super-achiever.jpg   -> Super Achiever Award
  tech-titan.jpg       -> Tech Titan Award

A card without an image shows a medal placeholder. To add more awards, add an entry
to `achievements` in src/data.js and use the same name for the image file.
Tip: keep each image under about 300 KB (resize to ~1200px wide) so the site stays fast.
