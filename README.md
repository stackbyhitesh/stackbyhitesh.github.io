# Hitesh Chaudhari – Portfolio

Personal portfolio of **Hitesh Chaudhari**, a Full-Stack Senior Software Engineer and Tech Lead based in Bengaluru. It shows my work, the results I have delivered and how to get in touch.

**Live site:** https://stackbyhitesh.github.io/
**LinkedIn:** https://linkedin.com/in/eng-hitesh-chaudhari

## What the site covers
- **About:** who I am, what I do and headline numbers (110M+ users reached on modules I led, 20+ production releases, 35K+ records rendered smoothly).
- **Experience:** OpenText, Bajaj Finserv, Chetu India, VPGP (EasyNow) and Fleet Solution, each with a plain-language summary, key results and the tech used, plus a career timeline.
- **How I work:** performance engineering, tech leadership, forward deployed delivery and AI-assisted development.
- **Projects:** multi-layer caching (−18% API response time), a RAG code assistant (−25% boilerplate time), a smooth UI for 35K+ records, an engineering CRM, an offline-first mobile app, and payments and SSO integrations. Filterable by category.
- **Achievements:** Hero's Award, Prodigy Award, Tech Titan Award and Office Olympix 1st place, with the certificates viewable full size.
- **Skills and education:** frontend, backend and APIs, AI-assisted development, data and cloud, payments and security, quality and delivery.
- **Contact:** a working contact form, plus email, phone, WhatsApp and LinkedIn links, and a downloadable resume.

## Highlights
- Dark and light themes (your choice is remembered).
- Quick menu with **Ctrl/⌘ + K** to jump to any section, switch theme, copy my email or download the resume.
- Works on desktop, tablet and phone, respects "reduce motion" and is keyboard friendly.
- Fast static site with no tracking and no third-party scripts.

## Built with
React 18, TypeScript, Vite and Tailwind CSS. Hosted on GitHub Pages. All content lives in `src/data.ts`.
